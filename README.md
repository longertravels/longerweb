# SMILE.DEEP — 独立站使用说明

你的个人品牌独立站已经建好了。这是**静态站 + 免费托管**方案：零月费、零后台、加载快、SEO 友好。
下面按「先上线 → 再改内容 → 再赚钱」的顺序写，照着做就行。

---

## 一、文件结构

```
site/
├── index.html          ← 英文首页（主站）
├── zh/index.html       ← 中文首页
├── assets/
│   ├── css/style.css   ← 全部样式，改配色只改顶部变量
│   ├── js/main.js      ← 移动端菜单，一般不用动
│   └── img/            ← 放照片的地方（目前为空，等你放）
└── README.md           ← 本文件
```

本地预览：双击 `index.html` 就能在浏览器里看。改完刷新即可。

## 二、上线前必须替换的 7 处

| # | 在哪 | 现在是什么 | 换成 |
|---|---|---|---|
| 1 | 两个 html 的 `<title>` / `description` | 默认文案 | 你的站点名 + 一句话定位（影响 Google 搜索结果） |
| 2 | 两个 html 里 `SMILE.DEEP` | 占位品牌名 | 你的正式站点名（**全局替换，一处都别漏**） |
| 3 | `index.html` 的 Hero | 渐变占位 | 放 `assets/img/hero.jpg`，并把 `<div class="ph-label">…</div>` 换成 `<img src="assets/img/hero.jpg" alt="…">` |
| 4 | 两个 html 的 Portfolio 六宫格 | 灰色占位框 | 替换成 `<img>`，做法同第 3 条 |
| 5 | 联系邮箱 / IG / TikTok | `hello@yourdomain.com` / `@your.handle` | 真实账号。**建议邮箱用域名邮箱**（如 hello@你的域名.com），比 gmail 专业很多 |
| 6 | 表单 `action` | `YOUR_FORM_ID` | Formspree ID（见第五节） |
| 7 | 商品区链接 | `#` | 换成联盟链接或商品页链接 |

> About 和「足迹」板块的个人资料（AIDA 2 持证、7 个国家、几乎走遍各省、西藏、丝路搭车、2027 长线 + AIDA 3 / OW / AOW）**都是按你告诉我的真实情况写的**，可以自由增删。
> 素材已在 `assets/img/` 之外不需要额外准备 —— 你手上的旅行和潜水照片就是全部内容。

## 三、域名：先买这个

**建议（按推荐度排序）**：

1. `smiledeep.com` — 短、好记，deep 双关「深海 / 深入」
2. `smilegoes.com` — 经典旅行博主命名法
3. `saltwatersmile.com` — 更有画面感，但长
4. `smilebelow.com` — below 是自由潜术语，圈内人一看就懂

- 买 `.com`，约 **¥90–120/年**；`.co` 要 ¥200+ 且辨识度反而低，不划算。
- 购买渠道：**Cloudflare Registrar**（最便宜，无溢价）或 Namecheap。
  如果走国内渠道（万网/腾讯）买 `.com`，境外托管**不需要备案**，但解析速度对国内访客略慢 —— 你的主要访客是海外品牌，这不是问题。
- **不要用免费二级域名**（如 xxx.netlify.app）做正式站：品牌方会觉得不专业，且没有域名邮箱。

## 四、免费上线：3 种方式（推荐第 1 种）

### 方式 1：Cloudflare Pages（推荐，最稳、全球 CDN）
1. 注册 [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Pages → Upload assets
2. 把整个 `site` **文件夹**拖进去，起个项目名 → Deploy
3. 部署完得到 `xxx.pages.dev`；在 Custom domains 里绑定你的域名，按提示改 DNS 即可
4. 以后更新：重新上传文件夹，或在 Pages 设置里连 GitHub 自动部署

### 方式 2：Netlify Drop（最简单，真的拖就行）
1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把 `site` 文件夹拖进去
2. 上线后 Site settings → Domain management 绑域名
3. 免费额度：100GB 流量/月，个人站完全够

### 方式 3：GitHub Pages（免费但要学一点点 Git）
适合以后想做版本管理的人。新手建议先跳过。

> **HTTPS 三家都自动开**，不用管。

## 五、联系表单怎么接（10 分钟）

静态站没有后端，用免费表单服务：

1. 注册 [formspree.io](https://formspree.io)，新建 Form
2. 拿到形如 `https://formspree.io/f/xrgjqkzd` 的地址
3. 把两个 html 里 `<form action="https://formspree.io/f/YOUR_FORM_ID">` 的 `YOUR_FORM_ID` 换成 `xrgjqkzd` 那一串
4. 免费版每月 50 条提交，起步够用。提交会直接发到你邮箱。

**不想折腾的替代方案**：把整个 `<form>` 删掉，换成一行
`<a class="btn btn-primary" href="mailto:hello@你的域名.com">给我发邮件</a>`

## 六、不上代码怎么更新内容

### 换照片
1. 图片放进 `assets/img/`（名字用英文，如 `hero.jpg`、`dive-01.jpg`）
2. 把占位块：
   ```html
   <div class="ph-label">你的照片 01<br>自由潜 / 水下</div>
   ```
   换成：
   ```html
   <img src="../assets/img/dive-01.jpg" alt="自由潜">
   ```
   ⚠️ 中文页在 `zh/` 里，路径要多一个 `../`；英文页直接 `assets/img/xxx.jpg`。

### 改文案
用记事本 / VS Code 打开 html，直接改文字。**只改标签中间的字，不要动 `<` 和 `>` 里面的东西**。
找不到位置就用 Ctrl+F 搜（比如搜「Shenzhen」「$150」「自由潜」）。

### 加一篇日记（Journal）
复制一整个 `<a class="post" href="#">…</a>` 块，粘贴在下面，改日期、标题、简介，`href` 换成文章链接。
暂时没有文章页就把 `href="#"` 留着，或者先指向你的小红书/公众号文章。

### 加商品
复制一个 `<div class="item">…</div>`，改封面、标题、描述、价格和按钮链接。

## 七、内容策略：怎么写才有人看（这块决定成败）

### 核心逻辑
品牌方不会凭空搜到你，他们是**搜某个具体问题**时看到你的文章，然后发现你还能拍素材。
所以网站不是作品集展示板，是**流量入口**。

### 你要写的长尾内容（举例）

**英文（面向海外品牌 + 国际潜水客群）**
- `Freediving in [目的地]: A Beginner's Guide`（每个你去过的潜点写一篇）
- `AIDA 2 Course Review: What I Wish I Knew`
- `Best Dive Mask for a Small Face (Women's Guide)`
- `[目的地] 10-Day Itinerary for Slow Travelers`

**中文（面向中文受众 + 反向导流 Shopee）**
- 自由潜考证全记录（AIDA2 备考 → 考试 → 拿证）
- 深圳练自由潜的现实方案
- 装备实测：百元 vs 千元面镜差在哪

### 三条铁律
1. **出发前就要开始写**。SEO 需要 6–12 个月才起量，等你明年上路再建站，那一年是零流量。
2. **每篇解决一个具体问题**，不要写「我的XX之旅」这种没人搜的流水账。
3. **每篇末尾都放一次合作入口**：「品牌合作请联系 hello@…」—— 这才是转化点。

## 八、变现：五条线，按这个顺序启动

| 顺序 | 收入线 | 什么时候开始 | 特点 |
|---|---|---|---|
| ① | **UGC 拍摄**（$150–300/条） | 现在就能接 | 现金流最快，但耗时间 |
| ② | **联盟营销** | 网站上线即可挂 | 零库存零售后，**睡觉也在赚** |
| ③ | **数字产品**（预设/攻略 PDF） | 内容攒到 10 篇后 | 做一次卖无数次，毛利近 100% |
| ④ | **服务**（行程规划 / 约拍） | 有粉丝后 | 客单价高，但用时间换钱 |
| ⑤ | **图片授权** | 素材多了之后 | 被动收入，可卖图库 |

**长线旅行状态下真正在赚的是 ②③⑤** —— 这也是为什么它们要现在就开始铺。

### 联盟平台（注册即用）
| 平台 | 适合推什么 | 备注 |
|---|---|---|
| Booking.com / Agoda | 酒店住宿 | 旅行类最好用，转化高 |
| Amazon Associates | 装备、相机配件 | 注意 180 天内需有成交否则封号 |
| 潜店 / 装备品牌自营联盟 | 面镜、脚蹼、湿衣 | 直接邮件问品牌要联盟链接，佣金更高 |
| Shopee 联盟 | 你店里的手机配件 | 中文站导流用 |

> ⚠️ **联盟链接必须在页面上标注**（网站已写了 disclaimer 文案，别删）。这是 FTC 合规要求，也是信任基础。

## 九、你最该在意的一件事：邮件列表

社媒账号会被封、算法会变，**邮件列表是你唯一真正拥有的资产**。

- 网站里已经有「自由潜入门清单 PDF — 留邮箱即送」这个诱饵（lead magnet），它就是这个作用。
- 免费工具：**Buttondown**（前 100 人免费）或 **MailerLite**（前 1000 人免费）。
- 目标：长线旅行出发前攒到 **300–500 个订阅者**。有这批人，你卖任何东西都有第一批买家。

## 十一、几个提醒

- **别贱卖**：报价锚点 1 分钟 ≈ $200（水下/潜水场景可加价 50–100%）。你一人包办脚本+拍摄+剪辑+沟通，还自付差旅。
- **授权要单独收钱**：素材买断 / 长期投流授权 = 基础价 +100%，否则会被无限白嫖。合同里写明使用渠道和期限。
- **小红书不能直接放外链**：想从国内平台导流，走「主页简介留邮箱」或私信，别在正文贴链接，会被限流。
- **和 Shopee 不冲突**：独立站是品牌资产（长期复利），Shopee 是现金流。两条腿走路，但独立站要趁早，因为它慢热。
